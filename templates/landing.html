Kemampuan Platform

Fitur Utama Sistem NOC

Didesain secara profesional untuk efisiensi pemantauan teknisi transmisi dan operator NOC.

Visualisasi Topologi Per Ring

Pemetaan alur transmisi horizontal yang menghubungkan Gardu POP Awal, titik DCU perantara, dan Gardu POP Akhir secara rinci dan jelas.

Deteksi Kabel Putus Instant

Indikasi warna kontras (Hijau Aman vs Merah Putus) pada setiap segmen bentangan kabel untuk mempercepat pemeliharaan di lapangan.

Otentikasi Dual-Role RBAC

Akses peran terstruktur. Administrator memiliki hak eksekusi edit & tambah data, sedangkan Viewer dibatasi dalam mode pemantauan saja.

Real-Time Event Stream (SSE)

Teknologi Server-Sent Events mengirimkan pembaruan status segmen ke seluruh browser operator secara langsung tanpa perlu reload halaman.

Integrasi Cloud Supabase

Dukungan penuh penyelarasan data ke PostgreSQL Supabase Cloud dengan cadangan SQLite lokal otomatis demi keandalan data.

Kalkulasi Otomatis Bentangan DCU

Penambahan titik gardu DCU secara otomatis mewarisi dan menghitung ulang jarak bentangan meter demi akurasi pemetaan.

FAQ Telemetri NOC

Informasi lengkap mengenai akses login, otentikasi peran, dan pengawasan jaringan.

Demi menjaga privasi dan keamanan infrastruktur ketenagalistrikan serta transmisi fiber optik PLN Icon+, akses penuh ke Dashboard Monitoring dan detail skema ring hanya dapat dibuka oleh pengguna yang terautentikasi (Admin atau Viewer).
Admin NOC memiliki akses penuh untuk mengedit status segmen (Aman/Putus), menambah/menghapus ring, mengatur titik gardu DCU, serta mengelola pembuatan akun pengguna baru. Sedangkan Viewer hanya memiliki akses baca (read-only) untuk memantau kontinuitas tanpa dapat mengubah data.
Sistem mengintegrasikan teknologi Server-Sent Events (SSE). Ketika teknisi atau admin memperbarui status kendala pada salah satu segmen gardu, sinyal pembaruan dikirimkan seketika ke seluruh tampilan browser operator secara otomatis tanpa perlu memuat ulang halaman.
Ya, seluruh rute kabel optik pada sistem ini diselaraskan menggunakan standar spesifikasi ADSS 24 Core dan penamaan titik berbasis Gardu Induk / DCU PLN Icon+.
Pengguna dapat menghubungi Administrator NOC PT PLN Icon Plus yang bertugas untuk melakukan reset password atau pembuatan kredensial akun baru melalui menu Manajemen Pengguna.

Siap Mengelola Operasional NOC PLN Icon+?

Silakan masuk dengan akun otentikasi Anda untuk mulai memantau skema topologi, mengelola titik gardu DCU, atau mengubah kontinuitas transmisi optik.
